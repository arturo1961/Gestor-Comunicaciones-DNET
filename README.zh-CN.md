# Gestor de Comunicaciones DNET 1.10.2

[Español](README.md) | [简体中文](README.zh-CN.md)

Gestor de Comunicaciones DNET 是一款面向 Windows 的免费开源联系人和通信记录管理工具。它可以筛选联系人、把所选地址复制到密件抄送（BCC/CCO），或在默认邮件程序中创建一封新邮件。

程序**不会自动发送邮件**，也不保存邮箱密码。每封邮件都由用户在自己的默认邮件程序和账户中亲自检查并发送。版本 1.10.2 在同一个可执行文件中提供 **62 种界面语言**、可配置图表以及受监督的单人邮件活动：主题、正文、文档链接、附件、可恢复队列、1 至 3,600 秒的可配置间隔，以及可修改的每日上限（初始值为 45）。

## 主要功能

- 新建、修改和受控删除联系人。
- 按国家、地区、语言、类型、组织和状态筛选。
- 根据可见或已勾选的联系人创建柱状图、条形图、饼图、环形图、折线图和面积图；可自由选择分组字段和筛选字段，并导出 PNG。
- 按姓名、邮箱、地点、组织、状态或备注即时搜索。
- 选择收件人并把地址复制到密件抄送（BCC/CCO）。
- 通过 `mailto` 在默认邮件程序中打开新邮件。
- 创建一次只包含一个收件人的受监督邮件活动，并保存主题、正文、附件和队列。
- 可以从选择器中把任意联系人字段以 `{字段}` 形式插入主题或正文，也可以继续手动输入花括号代码。
- 只有用户确认实际发送后才记录历史；用户可将两封邮件之间的等待时间设为 1 至 3,600 秒，并可修改每天确认的收件人数上限。
- 手动记录并查看通信历史。
- 使用回收站恢复联系人或永久删除联系人。
- 查找可能重复的联系人和格式不正确的邮箱地址。
- 使用红点标记“请勿联系”的地址，防止选择、生成邮件或通过导入重新加入这些地址。
- 从 Google/Outlook CSV、vCard（VCF）或 JSON 导入联系人；导入前会显示预览、检测重复项并自动创建备份，只保留最近两份导入自动备份。
- 将联系人导出为 JSON。
- 将联系人、历史记录和当前邮件活动完整备份为 ZIP。
- 恢复备份前，自动保存当前状态的安全副本。
- 自动把现有 JSON 数据迁移到 SQLite，并核对记录数量和数据库完整性。
- 继续更新兼容 JSON，以便在必要时返回旧版本。
- 检测旧版本所做的更改，并在重新导入前自动备份当前状态。

## 数据与隐私

GitHub 仓库中包含的数据文件是空的。程序首次运行时，会把工作数据复制到：

`%LOCALAPPDATA%\Gestor_Comunicaciones_DNET\`

从 1.7.0 版开始，`gestor_comunicaciones.db` 是主要数据库。首次启动时，程序会先自动创建原始 JSON 的 ZIP 备份，然后迁移全部记录；只有在数量与完整性检查通过后才启用新数据库。JSON 仍会作为兼容格式更新。如果旧版本修改了这些 JSON，新版本会检测到变化，先把当前状态保存为另一个 ZIP，再重新导入这些更改。

真实联系人、通信历史和当前活动只保存在用户自己的电脑上。`campana_actual.json` 可能包含主题、正文和附件路径。请勿公开该文件夹中的数据库、JSON 文件或程序生成的 ZIP 备份。

## 简明使用指南

1. 启动程序，使用“新建联系人”添加联系人，也可以导入 Google/Outlook CSV、vCard（VCF）或 JSON 文件，并在确认前检查预览。
2. 在顶部语言菜单中选择简体中文；选择结果会自动保存。
3. 使用搜索框或筛选器找到需要的联系人。
4. 勾选收件人。使用“选择可见联系人”可选择当前列表中允许联系的全部人员。
5. 群组邮件可以继续使用 BCC/CCO；逐个发送时，请打开“个人活动”。
6. 填写主题和正文，选择附件，然后使用已标记联系人创建队列。
7. 点击“准备下一封”只打开一个草稿。在邮件程序中亲自发送后，返回管理工具并确认发送。
8. 等待所选时间后继续下一位；达到所选每日上限时，队列会停止。
9. 在“工具”中可以打开回收站、查看历史以及检查重复联系人或错误邮箱。
10. 使用“备份 > 创建备份”，把联系人、历史和当前活动一起保存到 ZIP 文件。
11. 对要求停止联系的地址使用“标记为请勿联系”；红点表示该地址已被排除。
12. 使用“恢复备份”返回以前的状态；替换数据前，程序会自动备份当前状态，并继续保留“请勿联系”名单。

完整语言列表请参阅 [IDIOMAS.md](IDIOMAS.md)。自动生成的初始翻译可能需要改进，欢迎母语使用者提交修正。

## 下载与编译

已发布的 Windows 版本位于 [GitHub Releases 最新版本](https://github.com/arturo1961/Gestor-Comunicaciones-DNET/releases/latest)。

从源代码编译需要 Windows 10/11 和 .NET 8 SDK：

```powershell
dotnet build GestorComunicacionesDNET.csproj -c Release
```

生成 Windows x64 自包含单文件：

```powershell
dotnet publish GestorComunicacionesDNET.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none -p:DebugSymbols=false -o publicar
```
